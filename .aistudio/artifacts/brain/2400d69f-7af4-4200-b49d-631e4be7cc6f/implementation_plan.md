# خطة تنفيذ إعادة تعيين كلمة المرور عبر Gmail API (Google Workspace OAuth)

## نظرة عامة
بناءً على اختيارك، سنقوم بربط النظام رسمياً مع **Google Workspace APIs** عبر خدمة **Gmail API** بصلاحية الإرسال المحددة (`https://www.googleapis.com/auth/gmail.send`). سيتيح ذلك للنظام إرسال رسائل بريد إلكتروني حقيقية تصل مباشرة إلى صندوق الوارد في Gmail، تحتوي على رابط آمن وفريد ومؤقت لإعادة تعيين كلمة المرور، مع التحقق من استهلاك الرابط لمرة واحدة فقط.

---

## خطوات التنفيذ المقترحة

### 1. إعداد تفويض Google Workspace OAuth
- طلب تصريح Google OAuth عبر أداة `set_up_oauth` بالصلاحية الدقيقة:
  `https://www.googleapis.com/auth/gmail.send`
  (Least Privilege: تقتصر الصلاحية على إرسال رسائل التعيين فقط دون الوصول لقراءة البريد الشخصي).
- عرض بطاقة الربط للموافقة عليها.

### 2. محرك إرسال الرسائل عبر Gmail REST API
- بناء خدمة إرسال مخصصة `src/services/gmailSenderService.ts`:
  - صياغة رسائل MIME مشفرة بـ Base64URL مطابقة لمعايير RFC 2822.
  - إرسال الرسالة إلى نقطة نهاية Google الرسمية:
    `https://gmail.googleapis.com/gmail/v1/users/me/messages/send`
  - تضمين عنوان بريد المستلم (`ddzek258@gmail.com`)، ورابط إعادة التعيين الفريد والمؤقت.

### 3. نظام الروابط الآمنة أحادية الاستخدام (Single-Use Token Lifecycle)
- توليد رمز عشوائي تشفيري 32 بايت (`crypto.randomBytes(32)`).
- ربط الرمز ببريد المستخدم، وصلاحية زمنية محددة (60 دقيقة)، وحالة `used: false`.
- بمجرد استخدام الرابط لتعيين كلمة مرور جديدة، يتم وسمه فوراً كـ `used: true` ويُبطل نهائياً لمنع أي محاولة لإعادة الاستخدام.

### 4. واجهة المستخدم وتجربة إعادة التعيين
- **طلب إعادة التعيين**: إدخال البريد الإلكتروني والنقر على "إرسال رابط إعادة التعيين".
- **استلام الرسالة في Gmail**: تصل رسالة حقيقية إلى بريدك بعنوان *"إعادة تعيين كلمة المرور | شعبة الموائع المكمنية"* تحتوي على زر ورابط مباشر.
- **فتح الرابط وإعادة التعيين**: فتح الرابط من البريد والتحقق من صلاحيته لمرة واحدة، ثم إدخال كلمة المرور الجديدة وتأكيدها.

---

## خطة الاختبار والتحقق
1. استدعاء أداة تفويض Google Workspace OAuth وعرض البطاقة للموافقة.
2. تجربة طلب إعادة تعيين كلمة المرور لحسابك `ddzek258@gmail.com`.
3. التحقق من وصول الرسالة فعلياً إلى صندوق بريدك في Gmail وفتح الرابط.
4. تأكيد تغيير كلمة المرور والتأكد من إبطال الرابط لعدم إمكانية استخدامه مرة ثانية.
